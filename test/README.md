# 参考图验收

自动检查：`npm test`、`npm run build`。

浏览器验收使用 [fixtures/reference-circle.png](fixtures/reference-circle.png)，不需要私人照片：

1. 点击“上传参考图片”选择该文件，确认自动进入图片模式、显示图 1，预览和移除可用。
2. 检查多选/粘贴与最多三张的提示，以及损坏图片和大于 10 MiB 文件的错误。选择图片时不应发起上传请求。
3. 在手机尺寸下确认输入区无横向溢出、参考图和发送按钮可访问。退出图片模式、新建对话应清空待发送参考图。
4. 在线上提交一次“保持参考图的圆形主体和构图，将橙色圆改成蓝色，背景保持米白色，不要文字。”使用 1:1、1K。此步骤会调用图片服务并消耗一次生图额度；只在接口修改需要验收时运行。
5. 确认先上传参考图，再创建生图任务，完成后显示可预览、可下载的结果；失败时保留描述和参考图以便手动重试。

上传与任务请求可通过浏览器网络面板检查。不要记录或提交 API Key，服务端调试也只输出必要的错误结构。
